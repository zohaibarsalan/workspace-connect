01 / The connection

A small setup layer around the open-source Google Workspace MCP server. It handles local configuration; the upstream server supplies the Google tools.

Work from your files.

02 / Get connected

A little setup.
Then, just ask.

You’ll need Node.js 24+, uv, and Codex or Claude Code. Use your own Google Cloud project with the Drive and Docs APIs enabled.

Create a Web application OAuth client with this redirect URI:

http://localhost:8769/oauth2callback

Already connected? The installer preserves existing connections. See the repository’s migration notes before changing a shared MCP configuration.

  1. Get the connector

    git clone https://github.com/zohaibarsalan/workspace-connect.git
cd workspace-connect
npm ci && npm run build

  2. Add your own OAuth client

    Download its client JSON from Google Cloud. Import it into private local storage. 

    node dist/cli.js credentials --file ~/Downloads/client.json

  3. Register your agents

    node dist/cli.js install --client both

  4. Authorize Google

    On macOS, choose your browser. Elsewhere, open the printed Google URL yourself. Restart your agent sessions after installation. 

    node dist/cli.js auth --email you@example.com --browser Zen
03 / Your data

Runs locally.
Connects directly.

The connector runs on your computer and calls Google through the upstream MCP server. OAuth credentials stay in your local configuration directory.

When an agent reads a document, its contents may be sent to that agent’s AI provider under your account settings and that provider’s terms. This public website never receives your Google login or documents.

The connector has no subscription fee. Your AI provider, Google services, storage, and platform usage remain subject to their own pricing and limits. Google OAuth apps kept in Testing require reauthorization about every seven days.
